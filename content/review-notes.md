# Review notes

Words flagged while drafting for a native Dutch speaker to check (gender, plural, usage, translation).
Delete an item once checked; delete this file when it is empty.

- `they` (ze / they): ze also means she and them (unstressed); only 'they' shown on the card
- `whose` (wiens / whose): wiens is formal; 'van wie' is more common in speech
- `nor` (noch / nor): 'noch' is formal/literary
- `so-that-conjunction-opdat` (opdat / so that): formal, rare in speech
- `just-like` (evenals / just like): formal; zoals is more usual in speech
- `as-well-as` (zowel / as well as): Dutch is the pair zowel...als; English side simplified
- `do-particle` (wel / do): wel stresses a positive against a negative; no clean English equivalent
- `only-just` (pas / only just): pas = only just / not until; context-dependent
- `pardon` (wablief / pardon?): wablief is old-fashioned/humorous for 'what?'
- `will` (zullen / will): zullen has no participle; 'jij zult/zal' both used
- `people` (mensen / people): Dutch 'mens' (singular) exists but 'mensen' is the form learners need
- `ordinary` (gewoon / ordinary): gewoon is also an adverb ('just, simply')
- `bad-adjective-erg` (erg / bad): erg is also an adverb ('very')
- `fixed` (vast / fixed): vast has several meanings (firm, stuck, fixed); only 'fixed' shown
- `sir` (meneer / sir): plural of meneer: 'heren' (gentlemen) or 'meneren'
- `couple` (paar / couple): 'paar' = pair; 'een paar' = a few
- `matter-noun` (zaak / matter): zaak also means case, shop, business
- `damn` (verdomme / damn): mild profanity
- `get-verb-snappen` (snappen / get): colloquial
- `kind` (soort / kind): 'soort' is both de and het in usage
- `fault` (schuld / fault): schuld = guilt, fault and debt
- `guy` (vent / guy): informal
- `fellow` (kerel / fellow): informal
- `sentence` (zin / sentence): zin also means 'sense, desire' (zin hebben in)
- `girl-noun-meid` (meid / girl): informal / regional
- `hallway` (gang / hallway): gang also means 'pace, course'
- `attention` (aandacht / attention): 'aandacht' without a standard plural; sentence kept simple
- `guess` (raden / guess): raden: 'raadde' (guess) vs 'ried' (advise); check the past tense
- `concern` (betreffen / concern): formal verb
- `niece` (nicht / niece): nicht = niece or female cousin
- `slave` (slaaf / slave): historical/sensitive word
- `husband` (echtgenoot / husband): echtgenoot is formal; 'man' is the everyday word
- `brain` (hersenen / brain): Dutch plural-only 'hersenen'; English singular 'brain'
